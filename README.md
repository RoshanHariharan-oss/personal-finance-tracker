# Personal Finance Tracker

A lightweight, desktop-based finance management tool built with Python and Tkinter. This application allows users to log income and expenses, categorize transactions, and view a real-time summary of their financial health.

## ✨ Features
#User-Specific Data:Automatically generates a unique CSV file based on your system username.
#Real-Time Dashboard:Displays total Income, Expenses, and current Balance at a glance.
#Transaction Logging:Simple interface to add dates, types (Income/Expense), categories, and amounts.
#Data Table:Uses a `Treeview` interface for a clean, spreadsheet-style view of all transactions.
#Local Storage:All data is saved locally in the `data/` folder as a CSV file.

## 🚀 Getting Started

### Prerequisites
* Python 3.x
* Pandas library
